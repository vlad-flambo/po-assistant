## Order and dependencies
- 1 first because everything else compares hashes; it changes nothing stored. 2 is the only slice with a schema change and is rehearsed forward and backward on the restored dump before anything builds on it. 3 (read-only state) before 4 (writes) so the states are testable without a pass. 5 and 6 rewire existing paths onto the pass and so come after it is proven alone. 7 (the page) comes last among code because it only reads state and starts a pass. 9 needs everything before it. 11 and 12 are the owner's.
- Slices 1 to 8 change nothing hosted; slice 12 is the first and only hosted step, and its one irreversible-class part is the migration (additive and nullable: no table rewrite).

## Rollback
- Slices 1 to 10: revert the commits (nothing is hosted; the scratch database is dropped with `drop database scratch029`).
- Slice 2's migration: `migrate jobs 0044` drops the three columns; rehearsed backward in slice 2.
- Slice 12 on the host: the columns are nullable and additive, so redeploying the previous commit leaves them unused and harmless; if a reason arises to remove them, `migrate jobs 0044` on the host is the owner's step. A pass in flight when the old code goes back stays flagged and is simply never finished by the old code; pressing the old button scores everything.

## Risks
- **A thread in tests:** the existing suite stubs `recompute_in_background` so no thread runs behind a test. The new tests use the synchronous runner; the one test of the thread wrapper joins it.
- **The web start hook runs in every worker at once:** safe by the atomic claim (slice 4), tested with two threads.
- **A hash that misses an input:** criterion 13's replay is independent of the hash and would catch it in the drill.
- **Windows and SQLite timing:** heartbeat tests use a frozen clock, never sleeps.
- **The first host pass reads Neon.** Said before, measured after; no hosted pass happens without the owner's word.
- **The memory of a pass on a 512 MB instance** is unmeasured until slice 9; if the peak is near the limit the plan stops there and asks.
