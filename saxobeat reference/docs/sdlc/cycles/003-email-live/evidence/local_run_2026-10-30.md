# Slice 3: a local run with the console mail backend (2026-10-30, about 15:00 Paris time)

**How it was run.** In-process with Django's test client (the preview dev server cannot be pointed at a scratch database: its launch file has no environment overrides and `.env` holds the hosted database's address). `DATABASE_URL`, `SAXOBEAT_HOSTED_DATABASE_URL` and `SAXOBEAT_FALLBACK_DATABASE_URL` were all empty for the process; the database was a scratch SQLite file in the scratchpad (`rehearsal.db`, deleted afterwards); `SAXOBEAT_MAIL=console` (printed, nothing sent); `SAXOBEAT_PUBLIC_URL=https://jobs.stoyan.ovh`. The script asserts all three before it does anything. Nothing left the PC and no hosted database was touched.

**What the code did** (plain-text parts of the printed e-mails, decoded from quoted-printable):

French (account language `fr`), subject `Votre mot de passe Saxobeat`, from `Saxobeat <hello@mail.stoyan.ovh>`:

> Quelqu'un a demandé un nouveau mot de passe pour votre compte Saxobeat. Si c'est vous, choisissez-le ici :
> https://jobs.stoyan.ovh/reset/Mg/dh9r2n-…/
>
> Le lien ne sert qu'une fois, pendant 1 heure. Si ce n'était pas vous, ignorez cet e-mail : votre mot de passe ne change pas.

English (account language `en`), subject `Your Saxobeat password`:

> Someone asked for a new password for your Saxobeat account. If it was you, choose one here:
> https://jobs.stoyan.ovh/reset/Mg/dh9r2o-…/
>
> The link works once and for 1 hour. If it was not you, ignore this e-mail: your password stays as it is.

| Check | Result |
|---|---|
| Link host in both e-mails | `https://jobs.stoyan.ovh` (the public address set for the run) |
| The e-mailed link opens "Choose a new password" (French and English runs) | HTTP 200, text present, both times |
| The operator's hand-made reset message (console, *Reset password*) | "Password reset link for marie@example.com (valid for a few days; send it to them yourself): …", unchanged; its link opens "Choose a new password" (HTTP 200) |

**What this does not show:** the 1-hour and 3-day limits themselves (those are in the tests, which move the clock: `test_an_emailed_reset_link_works_for_an_hour_and_not_after`, `test_a_hand_made_reset_link_keeps_working_for_three_days`); real delivery (slices 7 to 10); a browser (the pages were fetched, not rendered).

**A finding, not fixed here:** the HTML part of the English e-mail starts `<html lang="fr">`. `jobs/templates/jobs/mail/_layout.html` reads `LANGUAGE_CODE`, which the mail renderer does not put in the context, so it always falls back to `'fr'`. Cosmetic (the text is English, the subject is English), and it predates this cycle; a candidate for the HTML e-mail polish (cycle 011).
