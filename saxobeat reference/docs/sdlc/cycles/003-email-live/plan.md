## Order and dependencies
- **Code before keys (slices 1 to 4 before 7).** Once mail is on, anyone can ask for a reset link by e-mail; the 1-hour code should already be on the host, or the first links would last 3 days.
- **Pause before the switch (5 before 7).** Switching on while candidate e-mails are not paused could e-mail every existing friend.
- **DNS before keys (6 before 7).** An unauthenticated domain sends to spam.
- **The switch is the last step of 7, and 8 stops the line:** no invitation (9, 10) before both inboxes and headers pass.
- Slices 1 to 3 are Claude's and can start the moment the plan is approved. Slices 5 and 6 are the owner's and can run in parallel with them; DNS records take time to spread, so starting slice 6 early costs nothing.
- Slice 11 needs the owner's OK each time, because it reads the hosted database.

## Rollback
| Slice | How to undo |
|---|---|
| 1 to 3 | Nothing to undo in production: tests, code and local files only; revert the commit if wanted |
| 4 | Revert the commit and push; Render redeploys. Migration 0042 only changes two defaults, and going back means a new migration, so push it only if the owner accepts it |
| 5 | Turn the pause off in the console |
| 6 | Remove the DNS records; delete the Brevo domain or key |
| 7 | Set `SAXOBEAT_MAIL=off` on Render and in `.env`: every e-mail then ends *skipped* and nothing leaves (covered by `tests/test_mail.py`, the "off" test). Revoking the API key in Brevo stops sending at once |
| 8 to 10 | An e-mail that was sent cannot be recalled; an invitation can be revoked in the console and a reset link stops working after its hour |

## Risks
- **Spam or failed authentication** at slice 8: the line stops there, nobody is invited, the records are fixed first.
- **The push carries other work** (slice 4): the owner sees the list before pushing.
- **The French sentence** is Claude's wording and goes to the owner in `evidence/french_to_read.md` (one sentence plus the "1 hour" form).
- **The working tree is shared with the 013 session** (uncommitted files in `jobs/services/ingest.py`, `jobs/sources/jsonld.py`, `jobs/management/commands/seed_employers.py`, `tests/test_more.py` and others): Claude commits only the paths in the slice, and a full-suite failure in one of those files is reported, not fixed here.
- **DMARC reports may not arrive** if the report address is on another domain than the sender's; no criterion needs them.
- **Brevo may ask for a card, a phone number or a business check** when the account is made: stop and tell Claude; nothing is bought without a yes.
