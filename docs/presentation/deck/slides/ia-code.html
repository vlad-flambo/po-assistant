Le partage des rôles

PackL’IA fait (jugement)Le code fait (calcul, vérification)

Demander le score au LLM : non reproductible, non auditable
1:30. Le LLM ne fait que du jugement, toujours justifié et modifiable par la PO. Tout ce qui se compte est compté par le code : Reach, RICE, ARR, tendances. Résultat : un arbitrage se rejoue en quelques secondes, et un « et si… » sur les poids ne coûte aucun appel à l’IA.
